# 성능·회귀 테스트·안정성 분석

orchestrator: Codex

사용자 요청: 질문 없이 기존 동작을 보존하는 성능 개선, 핵심·실패·빈 값·입력/권한 오류 테스트, 실패 경계 방어를 수행한다.
저장소: reverse-proxy-tutorial. 루트 AGENTS.md, CLAUDE.md, README와 소스 구조를 확인했다. 초기 Git 상태는 상위 오케스트레이터가 확인한 깨끗한 codex/workspace-environment-20260904 브랜치다.
가정: 기존 계약과 확인 가능한 소스만 기준으로 한다. 외부 서비스, 실제 자격 증명, 배포 및 UI 디자인 변경은 제외한다. 질문하지 말고 수정하라는 명시적 승인을 적용한다.
완료 기준: 근거 있는 변경과 경계 회귀 검증. 실행 환경이 없는 항목 및 변경 근거가 없는 항목은 별도로 기록한다.

확인 결과: 기존 base href 정규화와 forwarded header 등록을 회귀 검사했다. 확인한 범위에서 동작 보존 성능 변경 근거가 없어 운영 코드를 변경하지 않았다.
검증 범위 및 한계: 기존 루트 PathBase '/'가 '//'로 계산되는 동작도 그대로 기록한다. 신뢰 프록시 allow-list 정책은 임의 변경하지 않았다. 실제 HTTP/WebSocket E2E는 미검증.
